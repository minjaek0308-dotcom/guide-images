💡 카메라로 찍은 칠판 화면이 바래 보이거나 색이 다르게 나오나요?

전자칠판은 스스로 빛을 내는 화면이라, 카메라가 자동으로 색과 밝기를 맞추다 보면 색이 틀어지기 쉬워요. CameraCMS에서 화이트밸런스 · 채도 · 밝기만 조정하면 바로 좋아져요. 조정한 값은 카메라에 저장돼요 😊

이런 증상이면 이 문서를 보세요

  • 녹색 칠판 배경이 파랗거나 바랜 색으로 녹화돼요

  • 흰 바탕이 하얗게 날아가 글자가 잘 안 보여요

  • 화면 전체가 노랗게 / 파랗게 물들어 보여요

  • 칠판 화면에 줄무늬나 깜빡임이 보여요

🎥 카메라 앵글·트래킹 설정은 「웹캠 네트워크 + CMS 카메라 세팅 (T1 + Panorama)」 문서를 봐주세요.

1. 왜 이런 일이 생기나요?

  • 밝기 차이 — 전자칠판 화면은 교실보다 훨씬 밝아요. 카메라가 교실과 선생님에 맞춰 밝기를 잡으면, 칠판 화면은 너무 밝아져 색이 빠지고 흰 바탕이 날아가요.

  • 자동 화이트밸런스 — 카메라는 교실 조명과 칠판 빛이 섞인 상태에서 '흰색'을 자동으로 추정해요. 이때 색이 한쪽(파랑·노랑)으로 쏠릴 수 있어요.

  • 수동 화이트밸런스(MANUAL)로 바꾸면 빨강(R)과 파랑(B)의 세기를 직접 정해서 색을 고정할 수 있어요.

⚖️ AUTO vs MANUAL, 무엇을 쓸까요?

AUTO : 조명이 자주 바뀌는 교실(창문 빛이 많이 드는 곳 등)에 무난해요.

MANUAL : 조명이 일정한 교실에서 색을 정확히 고정하고 싶을 때 좋아요. 대신 조명이 크게 바뀌면 다시 맞춰야 할 수 있어요.

2. 시작 전에 준비해 주세요

  1. 실제 수업 자료를 칠판에 전체 화면으로 띄워 주세요. (예: 녹색 배경 슬라이드) 원격 화면이나 CMS 창을 칠판에 띄운 채로 보면, 카메라가 그 화면을 다시 찍어 색을 판단하기 어려워요.

  2. 흰색·회색 기준을 하나 정해 주세요. 칠판의 흰 테두리, 클래스인 칠판의 회색 배경 등이 좋아요. 이 부분이 흰색·회색으로 보이면 색이 맞은 거예요.

  3. 전자칠판에서 CameraCMS 실행 → Main View → 장치 목록의 ClassIn Cam T1 선택

3. 카메라 메뉴 조작법

왼쪽 Camera 패널의 버튼으로 카메라 화면 위에 뜨는 메뉴를 조작해요.

  • Menu : 카메라 메뉴 열기

  • ▲ ▼ : 항목 이동

  • ◀ ▶ : 값 낮추기 / 올리기

  • Enter : 선택 · 하위 메뉴 들어가기

  • Return : 뒤로 가기 · 메뉴 닫기

메뉴 첫 화면에는 IMAGE · EXPOSURE · COLORTONE · SYSTEM · DEVICE INFO가 있어요.

▲ 메뉴 첫 화면

⚠️ SYSTEM → DEFAULTS는 누르지 마세요. 지금까지 조정한 값이 모두 공장 초기값으로 돌아가요.

[[IMG07]]

▲ SYSTEM → DEFAULTS (누르지 마세요)

4. 색감 맞추기 (COLORTONE)

① 화이트밸런스를 수동으로

COLORTONE → WB를 AUTO → MANUAL로 바꿔 주세요. 아래에 MAN-RGAIN(빨강), MAN-BGAIN(파랑) 항목이 생겨요.

[[IMG03]]

▲ 변경 전 — WB AUTO

[[IMG04]]

▲ 변경 후 — ① WB MANUAL ② MAN-RGAIN · MAN-BGAIN

② 화면을 보면서 한 칸씩 조정

  • 파랗게 · 청록으로 보여요 → BGAIN ◀ (낮추기)

  • 노랗게 · 주황으로 보여요 → BGAIN ▶ (올리기)

  • 회색이 올리브색(녹색 기)으로 보여요 → BGAIN ▶ (올리기)

  • 분홍 · 붉은 기가 돌아요 → RGAIN ◀ (낮추기)

한 번에 한 칸씩 바꾸고 화면을 확인해 주세요. 기준으로 정한 흰색·회색이 흰색·회색으로 보이는 지점에서 멈추면 돼요.

③ 바랜 느낌 줄이기

SATURA(채도)를 1~2칸 올려 주세요. (예: 7 → 9)

🎨 HUE(색조)는 되도록 그대로 두세요. 칠판 색과 함께 선생님 피부색도 바뀌어요.

5. 밝기 맞추기 (IMAGE · EXPOSURE)

  • 흰 바탕이 날아가 글자가 안 보이면 → IMAGE → BRIGHTNESS를 1~2칸 낮춰 주세요.

  • 전자칠판 자체 밝기를 조금 낮추는 것도 효과가 있어요.

  • 칠판 화면에 줄무늬·깜빡임이 보이면 → EXPOSURE → ANTI-FLICKER를 60Hz(한국 전원 기준)로 맞춰 주세요.

[[IMG05]]

▲ IMAGE → BRIGHTNESS

참고: 같은 IMAGE 메뉴의 MIRROR · FLIP은 화면 좌우·상하 반전이에요. 색 보정과 관계없으니 그대로 두세요.

6. 마무리 (꼭 해주세요)

  1. Return을 여러 번 눌러 메뉴를 닫아 주세요. 메뉴가 열려 있으면 수업 화면과 녹화에 그대로 찍혀요.

  2. 클래스인에서 10초 정도 녹화한 뒤 다시보기로 색을 확인해 주세요. 실시간 화면보다 저장된 영상이 기준이에요.

  3. 조정한 값은 카메라 본체에 저장돼요. 전원을 껐다 켜도 그대로 유지돼요.

[[IMG06]]

▲ 조정 전 / 후

📌 참고값 (녹색 배경 칠판 · 실내 조명 교실 사례)

WB MANUAL · RGAIN 6 · BGAIN 9 · SATURA 9 · BRIGHTNESS 3

교실 조명마다 맞는 값이 달라요. 출발점으로만 쓰고 화면을 보며 조정해 주세요.

잘 안 될 때

메뉴가 수업 화면에 같이 보여요

CMS에서 Return을 여러 번 눌러 메뉴를 완전히 닫아 주세요.

값을 바꿨는데 색이 그대로예요

WB가 MANUAL인지 확인해 주세요. AUTO 상태에서는 R/B 값이 적용되지 않아요.

한쪽을 고치면 다른 색으로 쏠려요

정상이에요. 위 순서대로 B → R 순서로 한 칸씩 번갈아 맞춰 주세요. 처음부터 다시 하려면 WB를 AUTO로 돌렸다가 다시 MANUAL로 바꿔 주세요.

낮에는 괜찮은데 저녁 수업에 색이 달라요

수동 화이트밸런스는 조명이 바뀌어도 그대로예요. 주로 수업하는 시간대 조명에 맞춰 주세요. 시간대마다 조명 차이가 크면 WB AUTO를 권장해요.

칠판 화면이 일렁이고 흐려 보여요 (눈으로는 괜찮아요)

칠판 앞에 난방기·전열기구가 있는지 확인해 주세요. 열기가 아지랑이처럼 화면을 흔들 수 있어요. 기기를 끄면 바로 해결돼요.

4K 카메라인데 녹화 화질이 기대보다 낮아요

클래스인 수업 녹화는 최대 1080p예요. 색과 밝기를 맞추는 것이 선명도 개선에 더 효과적이에요.

누군가 DEFAULTS를 눌러 초기화됐어요

위 순서대로 다시 맞춰 주세요. 잘 안 되면 오른쪽 아래 채팅 버튼으로 문의해 주세요.
